# A股全市场扫描方案调研（2026-09-08 凌晨）

## 一、项目初心（为什么做这个）

原项目（TradingAgents fork + ai-hedge-fund fork）的定位是**对持仓池逐只深析**：
- `run_holdings --tickers config/tickers.yaml`：读 tickers 列表 → 每只跑 10 大师 + 多空辩论 + 研究员 + 交易员 → 落决策 + 飞书推送
- ai-hedge-fund：AI 对冲基金，也是给定标的池（tickers）驱动

**盲区**：只分析"已经持有的票"，不回答"明天该买什么新票"——即缺少**选股（机会发现）**环节。项目若要长期有意义，必须补上"全市场 → 候选 → 深析"的前端漏斗。

## 二、全市场扫描可行性（已验证 ✅）

**数据源（免费、无需登录、本机直连实测可达）：**

| 源 | 能力 | 验证结果 |
|---|---|---|
| **东财 push2.eastmoney.com clist** | 一次拉全市场(5556只)，按 涨幅/换手/成交额 排序，分页，板块过滤(fs 排除科创) | ✅ 实测拉到全市场并出候选 25 只 |
| **腾讯 qt.gtimg.cn/q=** | 批量实时行情(一次数百只)，含五档/成交额/换手 | ✅ 实测稳定 |
| **新浪 quotes.sina.cn** | 日 K + 实时 | ✅ 实测（项目现用源） |

**结论：全市场数据无技术障碍。** 扫全市场 ≈ 东财拉 50+ 页 或 拉涨幅榜前 N 页粗筛。

## 三、分层方案（让"全市场分析"可行）

直接对 5000 只逐只跑 LLM 深析不现实（单只 ~200s × 5000 = 11 天）。分层：

```
第 1 层 量化粗筛（免费数据，秒级，无 LLM）
  ├─ 东财/腾讯 全市场实时 → 按 涨跌幅/换手率/成交额/量比/均线 打分
  ├─ 排除: 科创板(688/689)、ST、退、北交所、次新(<60日)、停牌
  └─ 输出: 30~60 只候选（今日资金关注 + 形态健康）

第 2 层 LLM 深析（TradingAgents 现有管线，只对候选跑）
  └─ 每只跑 大师辩论→交易员，输出 建仓/增持/观望 决策 + 理由

第 3 层 汇总卡片 → 飞书（含: 今日候选、各自结论、与持仓对比）
```

**耗时估算**：粗筛 ~1min + 候选 40 只深析 ~40×200s≈2.2h（可 rounds=1 减半，或只深析 top 20）

## 五、注意

- 东财接口短时间多次请求会被临时封 IP（实测）——扫描要限速（每页间隔 3s+）或切腾讯
- 数据为 9-7 收盘后快照，验证用；实盘扫描在交易日盘中/收盘跑
